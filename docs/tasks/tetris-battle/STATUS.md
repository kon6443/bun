- 무엇을: 테트리스 2~4인 실시간 대전(방 생성·목록·비밀번호·콤보 공격·가비지·모바일 다인원 화면·채팅) + 싱글·대전 공통 화면 연출 강화
- 끝났다는 기준 (Q 확정 후 갱신):
  - 방을 만들고(비밀번호 선택) 목록·초대 링크로 2~4명이 들어와 방장이 시작한다. 틀린 비밀번호는 입장 거부

  - 가비지 대기열·상쇄·콤보 중 차단·0.5초 지연·피스당 8줄이 동작하고, 대전 리플레이를 재시뮬하면 같은 결과(골든)
  - 모바일 세로 화면에서 상대 미니보드·공격 대상·대기 가비지 게이지가 보이고 메인 판 조작이 기존과 같다

  - 경기 결과가 저장되고, 4분할 리플레이 재생 결과가 기록과 같으며, 카톡·링크로 공유된다(D-008)
