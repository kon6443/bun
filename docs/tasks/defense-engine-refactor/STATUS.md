- 무엇을: 디펜스 엔진(프론트 원본 `defense/engine`, 백엔드 사본 `src/modules/games/defense-engine`)을 결과 동일하게 리팩토링해 성능·구조를 개선한다. **0단계는 측정과 안전망만** — 엔진 파일은 바꾸지 않는다
- 0단계 끝났다는 기준:
  - 기준선 수치가 WORKLOG에 있다: 서버(Node, 실제 워커 dist) 검증 시간(골든·실제 랭킹 리플레이·최악 스트레스), 브라우저/프론트 하네스 시간(최악 (b)·이어하기 복원·재생 준비), 할당·GC(가능한 범위), 번들 크기(디펜스 경로 청크)
  - **차등 테스트 안전망**: 결정적 생성 코퍼스(시드 기반 봇·시뮬 판, 수천 판 이상, 무한·주간·캠페인 포함)의 최종 상태 해시 + 매 N틱 중간 해시를 "현재 엔진" 기준으로 고정한 테스트가 백·프에 있고, 지금 엔진으로 통과한다
  - **운영 리플레이 회귀**: 운영 DB의 디펜스 랭킹 리플레이(공개분) 전부를 현재 엔진으로 재검증해 저장 점수와 일치함을 확인하고, 익명화된 입력(이름·ID·IP 제외)을 회귀 픽스처로 둔다
  - 안전망이 실제로 잡는지 증명: 엔진에 의도적 1비트 변경(예: 데미지 +1)을 넣으면 실패함을 확인하고 되돌린다
