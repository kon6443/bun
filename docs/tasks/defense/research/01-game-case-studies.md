> 목적: 웹 디펜스 게임 신규 개발을 위한 레퍼런스. **구현 문서가 아니다.**
> 조사일: 2026-10-21 · 방법: 공식/위키(wiki.gg·Wikipedia·Blooncyclopedia)·스토어 페이지·리뷰 웹 검색.

## 표기 규칙 (읽기 전에)

| 표기 | 의미 |
|---|---|
| 수치 + `[n]` | 이번 조사에서 출처 페이지로 **확인한 값**. 번호는 문서 끝 "출처" 절 |
| `(미확인)` | 출처로 확인하지 못한 값. 널리 알려진 통념이라도 이번에 확인 못 했으면 이 표시를 붙였다. **설계 수치로 쓰기 전에 재확인 필요** |
| `(버전차)` | 패치·버전마다 달라지는 값. 출처끼리 불일치가 있었다 |

- Fandom 위키 일부는 이번 환경에서 접근이 막혀(HTTP 402/403) 검색 요약·다른 미러로 대체했다. 그래서 Kingdom Rush·Random Dice·GemCraft의 세부 수치는 `(미확인)` 비율이 높다.
- 게임 밸런스 수치(데미지·HP 등)는 버전마다 바뀌므로 **구조(규칙의 형태)** 위주로 정리했다.

## 1. Kingdom Rush 시리즈 (Ironhide, 2011~)

| 항목 | 내용 |
|---|---|
| 맵 구조 | 고정 경로, 다수 맵이 2~3갈래 분기·합류. 입구 여러 개 |
| 배치 규칙 | **고정 빌드 슬롯**(맵마다 정해진 원형 부지). 자유 배치 없음 → 맵 디자인이 난이도를 통제 |
| 타워 | 1편 기본 4종: 궁수·마법사·포병·병영(Barracks) [2]. 병영은 **적을 막아 세우는(blocking)** 유닛을 생산 |
| 업그레이드 | 3단계 업그레이드 후 **2개 중 1개 특화 타워 선택**(예: 마법사 → Arcane Wizard / Sorcerer) [2]. 특화 후 스킬 개별 업그레이드(미확인 단계 수). Vengeance는 16종 중 **최대 5종만 들고 입장**, 2택 특화 제거 [2] |
| 플레이어 스킬 | 쿨다운 2종: 범위 메테오 + 증원 병사 소환 [2] |
| 영웅 | 조작 가능한 영웅 1명, 맵 위 자유 이동, 레벨 클리어로 해금 [2] |
| 적 분류 | 지상/비행. 비행은 병영·포병이 공격 불가(미확인 — 통념). 물리방어(Armor)/마법저항(Magic Resist) 보유 적 존재(미확인 수치) |
| 데미지 타입 | 물리 vs 마법 + 방어/마저 비율 감소(미확인 세부) |
| 경제 | 킬 골드 + **다음 웨이브 조기 호출 시 보너스 골드 + 쿨다운 단축**(미확인 수치). 판매: 첫 웨이브 전엔 전액 환급 [1], 이후 부분 환급(미확인 %) |
| 생명 | 누수 1마리당 하트 차감(보스·대형은 더 많이) (미확인 기본 하트 수 — 통념 20) |
| 진행 | 클리어 + **추가 챌린지 모드로 별 획득** → 별로 영구 타워 업그레이드 트리 구매 [2]. 챌린지는 "더 어려운 배치·더 적은 자원" [2] (Heroic/Iron 명칭은 미확인) |
| 난이도 | Winter Storm 업데이트(2013)로 상위 난이도 추가 [2] |
| 랭킹 | 없음(싱글 별점 중심) |
| 웹/모바일 적합 | **원래 Flash 웹게임(Armor Games)**으로 출시 → 웹 TD의 정석 레퍼런스. 슬롯 배치=탭 1번, 1스테이지 10~15분(미확인) |

**배울 점**: 빌드 슬롯 + 2택 특화로 선택지를 "적지만 의미 있게" 만든다. 병영(blocking)이 고정 경로에 능동적 변수를 더한다.

## 2. Bloons TD 6 (Ninja Kiwi, 2018)

| 항목 | 내용 |
|---|---|
| 맵 구조 | 고정 경로(트랙). 맵 난이도 등급(초급~전문가)(미확인 구간 수) |

## 피해야 할 함정

1. **자유 배치 + 서버 검증 랭킹**: 좌표 실수(float)·물리 비결정성으로 재시뮬 불일치 위험. 자유 배치라면 그리드 스냅 + 정수/고정소수점 시뮬 필수.
2. **랜덤(RNG)에 랭킹을 걸기**: 머지·드로우 랜덤은 재미지만 랭킹 공정성을 해친다(Rogue Tower 분기 RNG 불만 [20]). 랜덤을 쓰면 **시드 고정 + 전원 동일 시드**.
3. **영구 메타 강화가 랭킹을 오염**: The Tower·Random Dice·Arknights처럼 영구 강화가 크면 랭킹 = 플레이 시간/과금 순위. 랭크 모드는 **메타 강화 비적용(정규화)**.
4. **PvP + 카드 레벨 = P2W 인식**(Random Dice·Rush Royale 비판). 초기엔 비동기 점수 경쟁만.
5. **업그레이드 조합 폭발**: BTD6 수준(타워당 3경로×5티어+파라곤)은 대형 스튜디오 밸런싱 예산 전제. 소규모는 KR식 3+2택.
6. **미로 차단 엣지케이스**: Fieldrunners·DG처럼 미로를 허용하면 "완전 차단 금지" 검사와 경로 재계산이 필요하고, 비행 적은 미로를 무시하므로 별도 설계 필요.
7. **지배적 경제 전략**: 이자 + 조기호출 + 경제 타워(바나나 농장)를 모두 넣으면 "초반 경제 몰빵"이 유일해법이 된다.
8. **긴 세션**: Mindustry·DunDef식 30분+ 세션은 웹 이탈률이 높다. 1판 5~10분 목표, 중간 저장 없이도 끝낼 수 있게.
9. **정보 부족한 즉사**: 웨이브 프리뷰(DunDef) 없이 위장·비행 적을 처음 보여주며 패배시키면 불공정 인식. 다음 웨이브 구성 미리보기 권장.
10. **판매 전액 환급**: 자유 재배치 남용(웨이브별 리스펙). 첫 웨이브 전만 전액(KR), 이후 부분 환급.
