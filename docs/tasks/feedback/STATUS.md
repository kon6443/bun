## 목표 & 수용 기준
- 무엇을: 로그인 유저가 BNB의 피드백 탭에서 피드백(제목·내용·카테고리)을 남기고, 마이페이지에서 내가 남긴 피드백과 처리 상태를 본다
- 끝났다는 기준 (Q1~Q4 확정 후 갱신):
  - 비로그인 유저는 피드백을 작성할 수 없다 — 서버는 401, 프론트는 기존 로그인 유도 패턴을 따른다
  - 제목·내용·카테고리 길이/값 위반은 422 `VALIDATION_ERROR`, 프론트도 같은 한도로 막는다 (DESIGN §2)
  - 마이페이지 "내 피드백"은 **내 것만** 최신순으로 보이고, 남의 피드백 ID로 상세 조회 시 404
  - 목록·상세에 카테고리·처리 상태·작성일(로컬 시각 표시)이 보인다
  - 사용자당 작성 빈도 제한 초과 시 429 (D-005)
  - 작성하면 운영자 디스코드·텔레그램에 알림이 간다. env가 없으면 보내지 않고 작성은 성공한다 (D-008)
  - 작성 후 수정·삭제 API가 없다 (D-009)
  - 테이블·전 컬럼에 코멘트가 있다
  - 백엔드 `pnpm ci:core`(경고 수 증가 없음) · 프론트 `pnpm ci:core` 통과, API·Playwright 실검증
- 비목표(1차): 다른 유저의 피드백 공개·투표, 관리자 웹 화면, 이미지 첨부(D-010), 수정·삭제(D-009)
