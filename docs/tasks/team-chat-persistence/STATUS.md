## 목표 & 수용 기준
- 무엇을: 팀 채팅 메시지 저장, 카톡식 안 읽은 인원 수, 읽은 사람·안 읽은 사람 표시, 안읽음 배지
- 끝났다는 기준:
  - 새로고침하거나 다시 들어와도 이전 대화가 보이고, 위로 스크롤하면 더 오래된 메시지를 불러온다
  - 4명 방에서 1명이 읽으면 다른 화면의 숫자가 소켓으로 즉시 1 줄어든다 (멀티 레플리카 포함)
  - 메시지마다 읽은 사람·안 읽은 사람 명단을 볼 수 있다
  - 팀 화면 채팅 버튼과 팀 목록 카드에 안읽음 배지가 보인다
  - 메시지는 최대 4,000자, 여러 줄 입력
  - 추방·비활성 멤버는 채팅을 보낼 수 없고 숫자 계산에서 빠진다
  - **새로 가입하거나 다시 활성화된 멤버는 이전 대화를 볼 수 있지만, 그 메시지들이 안읽음 배지에 잡히지 않는다 (D-012·D-021: 활성화 경로 3곳 전부)**
  - `pnpm ci:core` 통과(경고 수 증가 없음), 프론트 `bun run ci:core` 통과
- 비목표: 메시지 수정·삭제(D-010), 팀 목록 실시간 배지(D-008), 파일·이미지 전송, 푸시·텔레그램 알림
