### 백엔드 API (G2·G4·G5)

| 메서드·경로 | 용도 |
|---|---|
| `POST /games/tetris/sessions { board: 'daily' }` | 오늘의 테트리스 세션 → `daily-YYYY-MM-DD`, 전원 같은 seed. 비밀값이 없으면 503 `GAME_DAILY_UNAVAILABLE` |
| `POST /games/tetris/sessions { challengeScoreId }` | 도전장 세션 → `challenge-{원본 ID}`, 원본 seed. 엔진 버전이 다르면 409 `GAME_CHALLENGE_EXPIRED` |
| `GET /games/:gameType/rankings?board=daily-…\|challenge-…` | 데일리·도전장 순위 (period 무시) |
| `GET /games/:gameType/hall-of-fame` | 기간별 1~3위 (10분 캐시) |
| RankingItem `trophies` | 로그인 기록의 입상 배지 (필드 추가) |
