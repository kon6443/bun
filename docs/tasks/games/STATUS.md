## 목표 & 수용 기준
- 무엇을: 게임 모음집(`/games`)을 만들고 BNB "낚시" 탭을 "게임"으로 바꾼다. 1차 게임은 테트리스, 비로그인도 플레이하고 이름을 입력해 랭킹(일간·주간·전체)에 등록한다
- 끝났다는 기준 (Q1·Q2 확정 후 갱신):
  - BNB "게임" 탭 → 게임 목록에 테트리스·낚시가 보이고, 낚시는 기존처럼 동작한다
  - 비로그인·로그인 모두 테트리스를 끝까지 플레이할 수 있다(모바일 터치·데스크톱 키보드)
  - 게임 오버 후 이름을 입력해 랭킹에 등록하고, 일간·주간·전체 탭에서 순위를 본다
  - 서버가 리플레이(seed + 입력 기록)로 점수를 직접 계산한다 — 클라이언트 점수는 받지 않고, 재현 불가·시간 초과·세션 재사용은 거부 (D-005, DESIGN §4)
  - 같은 골든 리플레이 픽스처를 백·프 엔진이 같은 점수로 재현한다(양쪽 테스트)
  - 조작: PC 키보드·모바일 멀티터치 모두, 가이드라인급(SRS·홀드·고스트·DAS/ARR·락 딜레이) (D-009)
  - 이름 길이·금칙어 위반은 422, 등록 빈도 제한 초과는 429
  - 랭킹의 모든 기록을 비로그인도 재생할 수 있다 — 재생 결과 점수가 기록 점수와 같다, 배속·탐색 동작 (D-011)
  - 백엔드·프론트 `pnpm ci:core` 통과, API·Playwright 실검증
- 비목표(1차): 테트리스 외 신규 게임, 실시간 대전, 점수 공유 카드(후속 후보)
