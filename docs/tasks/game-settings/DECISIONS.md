## D-001 — 공통 설정 시트 + 기존 헤더·일시정지 톱니, 1~4단계 (2026-10-26, 사용자)
- **맥락**: 사용자 — "조작 모달이 테트리스 메인 페이지에 있는데 관리 쉽게", "공통 컴포넌트로 메뉴바 — 조작·사운드·스킨 설정 추가할 수 있게, 더 좋은 방법 있으면 제안". 프론트 조사로 (a) 상단 앱바 · (b) 공통 설정 시트 · (c) 설정 페이지 · (d) 기존 헤더에 덧붙이기 비교
- **결정**: (b)+(d) — 공통 `SettingsSheet` 껍데기 + 게임별 섹션 배열(props, 전역 레지스트리 없음), 각 화면 헤더·일시정지 메뉴에 톱니 `GameSettingsButton`. 1~4단계(껍데기 추출 → 조작 스토어 → 테트리스 연결 → 디펜스 이전), 단계마다 격리 커밋. (c) 설정 페이지·(5) 서버 동기화는 이번 범위 밖
- **근거**: (a)는 비게임 레이아웃까지 회귀 위험·비용 큼, (c)는 게임 중 이동 시 판 손실이라 결국 (b) 필요. (b)는 모달 2벌·디펜스 패널 통합, 중첩 모달 제거, 게임 중 같은 UI. 저장 키 유지로 마이그레이션 없음
- **영향**: 프론트 전용(백엔드 변경 없음)

## D-002 — UX 점검 후보 전부 이 작업에 포함 (2026-10-26, 사용자)
- **맥락**: WORKLOG 2026-10-26 UX 점검 표. 사용자 "전부 진행"
- **결정**: 표의 11건 전부(대전 입구 이름 오류 포커스 · 429 문구 · 게임 오버 버튼 위계·등록 불가 판 예상 순위 · 터치 기기 패드 안내 · 홈 진입점 · 데스크톱 홈 2단 · 세션 실패 문구 통일 · 리플레이 헤더 · 대전 ▲ 범례 · 게스트 도감 필터) + 기존 후보 리플레이 KeyOverlay 겹침. 가이드라인 차이 3건(엔진 규칙 변경)은 제외
- **분담**: 429는 백엔드 — `CustomThrottlerGuard`가 명세(`ApiTooManyRequestsErrorResponseDto`, 한국어)와 달리 라이브러리 원문("ThrottlerException: Too Many Requests")을 내보낸다 → 가드에서 명세 오류를 던진다. 프론트는 429에 탭 결과 캐시·디바운스. 나머지 프론트

## D-003 — 스킨 진입점을 눈에 띄게 (2026-10-26, 사용자)
- **맥락**: 사용자 "스킨 변경 메뉴도 눈에 좀 잘 띄었으면"
- **결정**: 설정 시트 안 섹션과 별도로 스킨 전용 진입점을 노출 — 테트리스 홈 상단(플레이 버튼 근처)에 현재 장착 미리보기 카드("내 스킨" + 바꾸기), 게임 오버·일시정지 화면에서도 접근. 세부 배치는 프론트 제안 → 스크린샷으로 확인
