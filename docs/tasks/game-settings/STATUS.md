## 목표 & 수용 기준 (D-001)
- 흩어진 게임 설정(조작·소리·스킨·연출)을 공통 설정 시트 하나로 — 각 화면 헤더·일시정지 메뉴의 톱니 버튼에서 연다
  1. 껍데기 추출: 공통 `SettingsSheet`(모바일 bottom sheet, sm↑ 패널) — 소리·스킨 모달이 사용, 동작 무변경(기존 테스트 통과)
  2. 테트리스 조작(DAS·ARR·진동) 구독 스토어 — 판 도중 변경은 다음 판부터(리플레이 헤더 기록), 회귀 테스트
  3. 테트리스 연결: 홈 헤더·플레이 HUD·일시정지·리플레이·대전에 톱니, 홈 인라인 설정 섹션은 진입 줄로 축소
  4. 디펜스 이전: SettingsPanel → 공통 시트, 중첩 모달 해소
- 저장: 기존 localStorage 키 유지(마이그레이션 없음), 스킨은 서버 스토어 유지
