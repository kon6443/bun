## D-006 — 포인트 적립 상한 방식 (2026-10-27)
- **상태**: ✅ 확정 (D-007 — 사용자 "추천대로")
- **측정 근거**: 운영 로그인 테트리스 기록(`db:select`, 2026-10-27) 63건·사용자 1명 — 판당 중앙값 65,905점·평균 75,838점·평균 7분 21초. 표본이 1명이라 기준이 약하다 → 출시 후 재조정 전제
- **제안** (판당 적립이 테트리스 한 판 중앙값과 비슷하게):
  1. **경기 적립**: 참가 20,000 + 승리(개인 1위·이긴 팀) 30,000 + KO당 10,000(최대 3). 4인 개인전 우승자 최대 약 80,000
  2. **유효 경기 조건**: 자기 턴 3회 이상 실제 발사(스킵 제외) · 경기 전체 6턴 이상 — 미달이면 0
  3. **승리·KO 보상은 로그인 사용자 2명 이상 경기에서만** — 게스트 상대(본인 부계정 게스트 포함)로는 참가 적립만
  4. **같은 상대 감쇠**: 같은 로그인 상대(조합)와의 경기는 KST 하루 기준 1~3번째 100% · 4~5번째 50% · 6번째부터 참가만
  5. **일일 상한**: 포트리스 적립 합계 KST 하루 **500,000**(테트리스 중앙값 약 7~8판, 스킨 Lv2 비용 10만의 5배) — 초과분은 잘라서 적립(원장 MEMO에 "일일 상한 도달")
  6. **동시성**: 상한·감쇠 계산은 적립 트랜잭션에서 그 사용자 `USERS` 행 잠금 후 오늘 원장 합계를 읽어 결정(skin-levels 강화 직렬화와 같은 방식) — 동시에 끝난 경기 2개가 상한을 넘기지 않게
  7. 로그인 판정은 경기 시작 시점 기준, 결과 화면 로그인 소급 없음
- **대안**: 상한 없이 감쇠만 · 적립 횟수 상한(하루 N경기) — 둘 다 설명은 쉽지만 장시간 파밍을 못 막거나 정상 유저가 빨리 막힌다.
