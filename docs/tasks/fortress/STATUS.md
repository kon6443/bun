## 목표 & 수용 기준
- 무엇을: 비로그인도 바로 하는 2~4인 개인전·팀전 턴제 포격 게임 + 리플레이·공유 + 로그인 보상(포인트·탱크 스킨)으로 재방문·유입 (D-001·D-002)
- 끝났다는 기준 (Q 확정 후 갱신):
  - 방을 만들고(비밀번호 선택) 목록·초대 링크로 2~4명이 들어와 개인전 또는 2:2 팀전을 시작한다
  - 턴마다 이동·각도·파워·무기로 발사하고, 바람·지형 파괴·낙하가 모든 화면에서 같게 보인다(서버 stateHash 일치)
  - 턴 시간 초과·끊김·이탈 정책이 DESIGN §3대로 동작하고, 마지막 생존 개인/팀이 승리한다
  - 경기 리플레이 재생 결과가 실제 경기와 같고, 링크·카톡으로 공유된다
  - 로그인 사용자는 경기로 포인트를 얻고 탱크 스킨을 장착·강화하며, 상대 화면·리플레이에 보인다. 파밍 상한이 동작한다
  - 비로그인은 로그인 없이 위 전부(보상 제외)를 할 수 있다
  - 테트리스 싱글·대전·디펜스 무회귀(기존 spec·E2E·골든)
  - 백·프 `pnpm ci:core`, WS E2E 다중 클라이언트, Playwright 2~4탭, 실기기
- 비목표(1차): 자동 매칭·레이팅, 관전, 아이템 상점, 3D (DESIGN §1)
